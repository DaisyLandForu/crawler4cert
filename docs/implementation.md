## paperCrawler / DBLP 审查

检查本地 sucv/paperCrawler `fa87bf2`：通用实现位于 `crawl_conf/crawl_conf/spiders/spiders.py:606` 的 DblpScrapySpider。会议入口使用 `/db/conf/<key>/index.html`，从年份标题与 toc-link 跳转论文目录；期刊使用 `/db/journals/<key>/index.html`，按年份找多卷目录。按 wanted_conf 的年份过滤，会议 zip 映射可能遗漏同年多卷。提取标题、作者、conf，PDF 和摘要为空，没有 DOI 和稳定 DBLP ID。

该本地 checkout 未发现 LICENSE/COPYING 或明确源码许可证声明，因此不复制其实现；仅参考流程，独立实现官方 DBLP JSON 搜索/记录格式。DBLP 元数据许可证与上游源码许可分开处理：元数据采用 CC0，见 https://dblp.org/faq/1474677.html；搜索 API 文档见 https://dblp.org/faq/How%2Bto%2Buse%2Bthe%2Bdblp%2Bsearch%2BAPI.html 。
